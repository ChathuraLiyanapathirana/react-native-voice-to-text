## Prerequisites

- Node 18 or newer. Yarn is bundled with the repo (`.yarn/releases`), so you do not install it separately. Do **not** use npm in this repo; it is a Yarn workspaces monorepo.
- A working React Native environment for React Native 0.78: see the [official setup guide](https://reactnative.dev/docs/set-up-your-environment).
- **Android:** Android Studio with the SDK, JDK 17, and NDK `27.1.12297006` (the version pinned in `example/android/build.gradle`). Make sure `ANDROID_HOME` points to your SDK, for example `~/Library/Android/sdk` on macOS.
- **iOS:** Xcode with a simulator runtime installed, and CocoaPods.
- **A real device is strongly recommended for speech testing.** Simulators and emulators only pick up audio if the host machine has a microphone, and recognition quality there is poor.

## Install

From the repository root:

```sh
yarn
```

This installs dependencies for both the library and the example app in one go.

For iOS, install the pods once (and again whenever native dependencies or the
spec change):

```sh
cd example/ios && pod install && cd ../..
```

`pod install` runs the library's codegen automatically (see the `pre_install`
hook in `example/ios/Podfile`).

## How the example is wired to the library

- The example lives in `example/` and is a Yarn workspace that depends on the library at the repository root.
- `example/metro.config.js` uses the `react-native-builder-bob` Metro config, so Metro serves the library's JavaScript straight from `src/`. Edits there hot-reload in the running app with no rebuild.
- The native code in `android/` and `ios/` is compiled into the example app by autolinking. Native edits need an app rebuild.
- Codegen output goes to `android/generated` and `ios/generated` (both git-ignored). It is regenerated by `pod install` on iOS, by the React Native Gradle plugin on Android, and by `yarn prepare`.

## Run the example app

Always start from the repository root.

### 1. Start Metro

```sh
yarn example start
```

Leave this running in its own terminal.

### 2. Android

Plug in a device with USB debugging enabled, or start an emulator, then:

```sh
yarn example android
```

Useful variations:

```sh
# Pick a device when several are connected (see `adb devices` for the serial)
yarn example android --device <serial>

# Build only the ABI of the connected device (much faster)
yarn example android --active-arch-only
```

Grant the microphone permission when the app asks. If the app cannot reach
Metro on a physical device, forward the port:

```sh
adb reverse tcp:8081 tcp:8081
```

### 3. iOS

```sh
yarn example ios
```

Useful variations:

```sh
# List simulators and devices
yarn example ios --list-devices

# Run on a specific simulator
yarn example ios --simulator "iPhone 17 Pro"

# Run on a connected iPhone (requires a signing team set in Xcode)
yarn example ios --device
```

For a physical iPhone, open `example/ios/VoiceToTextExample.xcworkspace` in
Xcode once and set your team under **Signing & Capabilities**.

### 4. Use the app

The example screen shows the current recognition language, a **Start
listening** button for single-shot recognition, and a **Hold to talk** button
for continuous mode. **Advanced testing settings** exposes the options passed
to `startListening()`.

## Work on the library in dev mode

### JavaScript changes

Edit files under `src/`. Metro picks them up and Fast Refresh updates the
example app immediately. Nothing to rebuild.

### Native changes

Edit `android/src/main/java/com/voicetotext/*.kt` or `ios/VoiceToText.{h,mm}`,
then rebuild the app:

```sh
yarn example android
```

```sh
yarn example ios
```

You can also work in the IDEs:

- **Android Studio:** open `example/android`. The library sources appear under the `react-native-voice-to-text` module.
- **Xcode:** open `example/ios/VoiceToTextExample.xcworkspace`. The library sources are under **Pods > Development Pods > VoiceToText**.

Native logs while the app runs:

```sh
adb logcat | grep -E 'VoiceToTextModule|ReactNativeJS'
```

```sh
yarn example ios --verbose
```

### Changing the native interface

The TurboModule spec is `src/NativeVoiceToText.ts`. After changing it:

1. Regenerate the codegen output:

   ```sh
   yarn prepare
   ```

2. Update the native implementations so they match the new spec. On Android the Kotlin module extends the generated `NativeVoiceToTextSpec`, so a mismatch is a compile error. On iOS the `RCT_EXPORT_METHOD` signatures in `ios/VoiceToText.mm` must match the spec.
3. Re-run `pod install` in `example/ios`, then rebuild both platforms.

### Building the package output

`yarn prepare` runs `react-native-builder-bob` and writes the CommonJS, ESM,
and TypeScript declaration outputs to `lib/`, plus the codegen output. This is
what gets published; the example app does not need it.

To start from a clean slate:

```sh
yarn clean
```

## Test both React Native architectures

The library runs as a TurboModule on the New Architecture and falls back to the
legacy bridge when an app disables it. The example uses the New Architecture by
default. To exercise the legacy path:

**Android**

```sh
cd example/android && ./gradlew :app:installDebug -PnewArchEnabled=false
```

Then launch the app from the device. Setting `newArchEnabled=false` in
`example/android/gradle.properties` has the same effect for `yarn example android`.

**iOS**

```sh
cd example/ios && RCT_NEW_ARCH_ENABLED=0 pod install && cd ../..
yarn example ios --device
```

Run `pod install` again without the variable to return to the New Architecture.

To confirm which mode is active, look for the startup line in the device log.
The New Architecture prints `"fabric":true`, the legacy bridge does not:

```
Running "VoiceToTextExample" with {"fabric":true,"initialProps":{},"rootTag":1}
```

> **Known limitation:** React Native 0.78.1 with the New Architecture disabled
> shows a blank screen on the iOS simulator and never loads from Metro, even for
> an app with no third-party modules
> ([facebook/react-native#50168](https://github.com/facebook/react-native/issues/50168)).
> Test the legacy iOS build on a physical iPhone.

## Troubleshooting

**`pod install` fails with "Unicode Normalization not appropriate for ASCII-8BIT".**
The shell locale is not UTF-8. Export it and retry:

```sh
export LANG=en_US.UTF-8 LC_ALL=en_US.UTF-8
```

**Gradle says "SDK location not found".**
Export `ANDROID_HOME`, or create `example/android/local.properties` containing
`sdk.dir=/path/to/your/sdk`.

**"adb: more than one device/emulator".**
Pass `--device <serial>` to the run command, or export
`ANDROID_SERIAL=<serial>`.

**The app shows "Unable to load script" or a red screen about Metro.**
Make sure `yarn example start` is running, and on a physical Android device run
`adb reverse tcp:8081 tcp:8081`.

**JavaScript throws "'VoiceToText' could not be found".**
The native module is not in the build. Re-run `pod install` (iOS) or rebuild
the app (Android). If the spec changed, run `yarn prepare` first.

**Stale native or codegen output after switching branches.**

```sh
yarn clean && yarn prepare
```

Then `pod install` and rebuild.

**No transcript on a simulator or emulator.**
Expected if the host machine has no microphone. Use a physical device.
